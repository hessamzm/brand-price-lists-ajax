# Brand Price Lists AJAX

افزونه وردپرس/ووکامرس برای نمایش **لیست قیمت محصولات بر اساس برند** با تمرکز بر سرعت، بارگذاری مرحله‌ای و تجربه کاربری مناسب در دسکتاپ و موبایل.

## Overview

این افزونه ابتدا فقط **لیست برندها** را تولید می‌کند. محصولات هر برند بعداً با **AJAX** و به‌صورت مرحله‌ای دریافت می‌شوند؛ بنابراین تعداد زیاد محصولات فروشگاه باعث تولید HTML و Queryهای سنگین در لود اولیه صفحه نمی‌شود.

هر درخواست AJAX حداکثر **۵ محصول** را دریافت می‌کند و در صورت وجود محصولات بیشتر، دکمه **بارگذاری محصولات بیشتر** فعال می‌ماند.

## Features

- نمایش همه برندهای غیرخالی در مرحله اول
- بارگذاری محصولات هر برند با AJAX
- بارگذاری اولیه ۵ محصول برای هر برند
- دکمه «بارگذاری محصولات بیشتر» برای محصولات باقی‌مانده
- Lazy Load برای تصاویر برند و محصولات
- استفاده از `IntersectionObserver` برای شروع بارگذاری برندهای نزدیک به viewport
- Cache کوتاه‌مدت برای لیست برندها
- انتخاب taxonomy برند از تنظیمات
- حفظ تنظیمات فعلی افزونه
- امکان روشن/خاموش کردن ستون‌های محصول
- امکان تغییر عنوان ستون‌ها
- پشتیبانی از تصویر، نام، SKU، قیمت، قیمت ویژه، موجودی، دسته‌بندی و دکمه مشاهده محصول
- طراحی Card-based با نسبت تقریبی **۱۰٪ برای اطلاعات برند و ۹۰٪ برای جزئیات محصولات**
- چیدمان زیگزاگی راست/چپ برای برندها
- طراحی Responsive برای موبایل و دسکتاپ
- استفاده از Nonce برای درخواست‌های AJAX
- بدون نیاز به تغییر شورت‌کد فعلی

## Shortcode

شورت‌کد اصلی:

```text
[sayeh_price_list]
```

برای نمایش یک برند خاص:

```text
[sayeh_price_list brand="hikvision"]
```

> برای حفظ سازگاری، نام شورت‌کد `[sayeh_price_list]` در این نسخه تغییر نکرده است.

## Installation

1. فایل ZIP افزونه را از بخش Releases یا فایل پروژه دریافت کنید.
2. در پیشخوان وردپرس به `افزونه‌ها > افزودن > بارگذاری افزونه` بروید.
3. فایل ZIP را نصب و فعال کنید.
4. از منوی **لیست قیمت برندها** تنظیمات را بررسی کنید.
5. شورت‌کد `[sayeh_price_list]` را در برگه موردنظر قرار دهید.

## Settings

صفحه تنظیمات افزونه شامل موارد زیر است:

- عنوان لیست
- Taxonomy برند
- نمایش هدر برند
- نمایش لوگوی برند
- تعداد محصولات سازگار با تنظیمات قدیمی افزونه
- ترتیب نمایش برندها بر اساس نام یا تعداد محصولات
- انتخاب ستون‌های خروجی و عنوان هر ستون

### Compatibility note

تنظیم `per_page` برای سازگاری با نسخه‌های قبلی حفظ شده است؛ مکانیزم AJAX در این نسخه برای بارگذاری هر مرحله از مقدار ثابت **۵ محصول** استفاده می‌کند.

## Performance Architecture

در لود اولیه:

```text
Page Request
   ↓
Brand Query + Short HTML
   ↓
Browser renders brand cards
   ↓
AJAX requests near viewport
   ↓
5 products per request
   ↓
Load more when needed
```

این معماری نسبت به تولید تمام جدول محصولات در درخواست اولیه، تعداد عملیات ووکامرس و حجم HTML اولیه را کاهش می‌دهد.

## Development Roadmap

نسخه‌های آینده قابلیت‌های سفارشی‌سازی بیشتری برای ظاهر لیست قیمت خواهند داشت. مسیر توسعه برنامه‌ریزی‌شده شامل موارد زیر است:

### Phase 1 — AJAX Performance

- بارگذاری مرحله‌ای محصولات
- کاهش Queryهای اولیه
- Lazy Load تصاویر
- بهینه‌سازی تجربه نمایش برندها

### Phase 2 — Multiple Styles

افزوده‌شدن چند استایل آماده برای نمایش لیست قیمت تا مدیر سایت بتواند بدون تغییر کد، ظاهر خروجی را انتخاب کند.

نمونه سبک‌های قابل توسعه:

- Classic Table
- Modern Cards
- Compact Price List
- Minimal
- Brand Showcase

### Phase 3 — Style Customizer

در مراحل بعدی امکان شخصی‌سازی رنگ‌ها، فاصله‌ها، تایپوگرافی، شکل کارت‌ها و نحوه نمایش قیمت‌ها در نظر گرفته خواهد شد.

## Security

- درخواست‌های AJAX با WordPress Nonce محافظت می‌شوند.
- خروجی‌های متنی و URLها قبل از نمایش Escape می‌شوند.
- دسترسی به WooCommerce و taxonomy قبل از پردازش بررسی می‌شود.
